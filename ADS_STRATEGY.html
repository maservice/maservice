8. Ставки и стратегия

Яндекс.Директ — Поиск

  • Стратегия: «Максимум конверсий» по цели click_phone
  • Недельный бюджет: ~45 BYN/нед (~180 BYN/мес)
  • Ограничение ставки: ≤ 0.50 BYN за клик
  • После 2 недель — «Оплата за конверсии» (если доступно)

Яндекс.Директ — РСЯ

  • Стратегия: ретаргетинг, оплата за показы
  • Бюджет: ~10 BYN/нед (~45 BYN/мес)

Google Ads — Поиск

  • Стратегия: «Максимум кликов» с ограничением дневного бюджета
  • Дневной бюджет: ~2.5 BYN/день (~75 BYN/мес)
  • Ограничение CPC: ≤ 0.40 BYN

9. План запуска (по неделям)

Неделя 1 — Подготовка

  • Создать аккаунт Яндекс.Директ: direct.yandex.ru
  • Создать аккаунт Google Ads: ads.google.com
  • Привязать Яндекс.Метрику к Директу
  • Настроить цели в Директе (импорт из Метрики)
  • Создать кампании по структуре выше
  • Загрузить тексты объявлений
  • Добавить минус-слова
  • Настроить UTM-разметку
  • Геотаргетинг: Минск + 50 км

Неделя 2 — Тестовый запуск

  • Запустить Поиск в Директе (без РСЯ)
  • Запустить Поиск в Google Ads
  • Мониторить ставки и CTR ежедневно
  • Через 7 дней — первый анализ

Неделя 3 — Оптимизация

  • Отключить ключи с CTR < 2% и без конверсий
  • Поднять ставки на конверсионные ключи
  • Добавить минус-слова по поисковым запросам
  • Запустить РСЯ-ретаргетинг
  • A/B-тест заголовков

Неделя 4 — Масштабирование

  • Оценить ROMI по каждой группе
  • Перераспределить бюджет
  • Решить: увеличить / оставить / изменить стратегию
