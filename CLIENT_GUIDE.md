# Руководство заказчика сайта maservice.by

Документ описывает, где и как размещён сайт, какие сервисы подключены и где находятся панели управления. Без технических подробностей — только то, что нужно знать для повседневной работы.

---

## 1. Адрес сайта

- **Основной домен:** https://maservice.by
- **С www:** https://www.maservice.by (автоматически перенаправляет на основной домен)

Сайт открывается с любого устройства, адаптивный (телефон/планшет/компьютер).

---

## 2. Где физически размещён сайт

Сайт состоит из готовых файлов (HTML, картинки, иконки). Эти файлы хранятся и раздаются бесплатно через **GitHub Pages** — сервис компании GitHub.

- **Хостинг файлов сайта:** GitHub Pages (США, глобальная сеть доставки)
- **Домен и защита:** Cloudflare (см. ниже)

GitHub Pages бесплатен для открытых проектов и надёжно работает для небольших сайтов-визиток. Платить за хостинг не нужно.

---

## 3. Cloudflare — что это и зачем

**Cloudflare** — это сервис, который стоит «перед» сайтом и выполняет три задачи:

1. **DNS (адресация).** Именно Cloudflare управляет доменом `maservice.by` — указывает, куда ведёт адрес.
2. **Защита.** Cloudflare поглощает атаки (DDoS), фильтрует ботов, скрывает реальный сервер.
3. **Скорость.** Картинки и страницы кэшируются на серверах Cloudflare по всему миру — сайт открывается быстрее для посетителей из разных регионов.
4. **SSL-сертификат (https).** Замок в адресной строке и защищённое соединение выдаётся именно Cloudflare, автоматически и бесплатно.

### Где панель Cloudflare

- **Адрес:** https://dash.cloudflare.com
- **Вход:** по логину и паролю, которые вы создавали при регистрации
- **Внутри выбрать домен:** `maservice.by`

Что можно делать в панели Cloudflare:
- **DNS** — список адресов (записей) домена. Менять без необходимости не нужно.
- **SSL/TLS** — настройки защищённого соединения и сертификата.
- **Rules → Redirect Rules** — правило перенаправления `www` → основной домен.
- **Analytics** — посещаемость на уровне Cloudflare (количество запросов, страна, трафик).
- **Caching** — управление кэшем (можно очистить, если сайт не обновился).

## 4. Где хранится код сайта

Исходный код сайта лежит в репозитории **GitHub**:

- **Адрес:** https://github.com/maservice/maservice
- **Вход:** по логину `maservice` (отдельный аккаунт, созданный под клиентский проект)

В репозитории две основные ветки:
- **main** — исходный код сайта (шаблоны, тексты, картинки, настройки)
- **gh-pages** — готовая собранная версия сайта, которую видят посетители (генерируется автоматически)

При любых изменениях в `main` сайт автоматически пересобирается и публикуется — вручную ничего делать не нужно.

## 5. Какие счётчики и сервисы аналитики подключены

### 5.1. Google Tag Manager (GTM)

**GTM** — это «контейнер», через который можно подключать разные счётчики и пиксели (Яндекс.Метрика, Google Analytics, рекламные пиксели и т.д.) без правки сайта.

- **ID контейнера:** `GTM-WFGJFGJG`
- **Уже встроен в сайт** на всех страницах
- **Панель GTM:** https://tagmanager.google.com
- **Вход:** Google-аккаунт, к которому привязан контейнер

Через GTM можно:
- Добавлять новые счётчики без программиста
- Управлять пикселями рекламы
- Настраивать отслеживание событий (клики, прокрутка, формы)

### 5.2. Яндекс.Метрика (счётчик 112675558)

Счётчик **уже встроен в сайт** на всех страницах и активирован.

- **Номер счётчика:** `112675558`
- **Панель:** https://metrika.yandex.ru
- **Вход:** Яндекс-аккаунт, к которому привязан счётчик

На сайте настроены цели (отслеживаются автоматически):
- **click_phone** — клик по номеру телефона
- **click_messenger** — клик по мессенджеру (Viber/Telegram/WhatsApp)
- **click_map** — клик по карте/маршруту

В панели Метрики доступны: Вебвизор (запись действий посетителей), карта кликов, отчёты по источникам трафика, страницам, времени на сайте.

### 5.3. Подтверждение домена в Яндекс.Вебмастере

На сайте размещён файл подтверждения `yandex_73064c36d4571327.html` — он доступен по адресу:
- https://maservice.by/yandex_73064c36d4571327.html

Это позволяет добавить сайт в **Яндекс.Вебмастер**:
- **Адрес:** https://webmaster.yandex.ru
- **Назначение:** проверка индексации, ошибки сканирования, позиция в поиске Яндекса

### 5.4. Google Search Console (рекомендуется подключить)

Для отслеживания индексации в Google:
- **Адрес:** https://search.google.com/search-console
- **Способ подтверждения:** через запись DNS в Cloudflare (TXT-запись) или через GTM

## 6. Где что меняется (краткая шпаргалка)

| Что нужно изменить | Где это делается |
|---|---|
| Текст на странице | Репозиторий GitHub → соответствующий файл в `src/pages/` |
| Тексты услуг | Репозиторий GitHub → `src/content/services/*.md` |
| Телефон, адрес, часы работы, email | Репозиторий GitHub → `src/data/siteConfig.ts` |
| Картинки услуг | Репозиторий GitHub → `public/images/services/` |
| Редирект `www` → основной домен | Cloudflare → Rules → Redirect Rules |
| SSL-сертификат | Cloudflare → SSL/TLS (выдаётся автоматически) |
| Счётчики аналитики | Google Tag Manager → https://tagmanager.google.com |
| Индексация в Яндексе | Яндекс.Вебмастер → https://webmaster.yandex.ru |
| Индексация в Google | Google Search Console → https://search.google.com/search-console |
